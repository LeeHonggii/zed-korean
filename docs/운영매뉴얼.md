한글 Zed + Claude/Codex IDE를 **고치고·빌드·설치**할 때 실수 없이 하기 위한 체크리스트.

## 1. 코드 수정 → 재빌드·재설치 (가장 많이 하는 작업)

**원칙: 소스(.rs)를 고쳤으면 재빌드. 설정(settings/keymap/tasks)·테마·아이콘은 저장만 하면 즉시 반영(재빌드 불필요).**

```bash
# 1) 컴파일 체크 (빠름, 깨졌는지 먼저 확인 — 고친 크레이트 지정)
cd ~/Tools/zed-src && export PATH="$HOME/.cargo/bin:$PATH"
cargo check --release -p <고친_crate>   # 예: sidebar, agent_ui

# 2) 빌드 (증분, 보통 2~5분)
./script/bundle-mac -l
#   ⚠ 끝에 "dmg-license: command not found" 는 무해(앱은 생성됨)

# 3) 재설치 (Zed 종료 → 교체 → 재실행)
osascript -e 'quit app "Zed"'; sleep 2; pkill -x zed; sleep 1
BUILT=~/Tools/zed-src/target/aarch64-apple-darwin/release/dmg/Zed.app
rm -rf /Applications/Zed.app && cp -R "$BUILT" /Applications/Zed.app && xattr -cr /Applications/Zed.app
open /Applications/Zed.app
```

→ repo의 `scripts/update.sh` 가 1~3을 한 번에. (번역 재적용 포함)

### ⚠ 자주 나는 실수 (방지)
- **"Zed가 2개 떠요"** → 빌드 산출물(target 안 Zed.app)이 Spotlight에 잡힌 것. **이미 `~/Tools/zed-src/target/.metadata_never_index`로 색인 제외**해서 재발 안 함. 그래도 뜨면 `rm -rf target/.../dmg/Zed.app` + `lsregister -f /Applications/Zed.app`.
- **`strings`로 한글 확인하면 안 보임** → 한글은 UTF-8이라 `grep -a -c "스레드" <바이너리>` 로 확인. 주석(//)은 컴파일되며 제거되니 주석으로 패치 여부 확인 금지.
- **재설치 전 Zed 꼭 종료** (실행 중 교체하면 꼬임).
- **Metal/Xcode**: 빌드엔 전체 Xcode + Metal Toolchain 필요(이미 설치됨). Xcode 자동 업데이트 불필요.

## 3. 에이전트 (Claude / Codex)

- 설정: `~/.config/zed/settings.json` 의 `agent_servers`.
- **Claude**: `node ~/Tools/claude-agent-acp/dist/index.js` + env(`CLAUDE_ACP_ALL_SESSIONS=1`, `CLAUDE_ACP_HIDE_AUTOMATION=1`, `CLAUDE_CODE_EXECUTABLE=~/.local/bin/claude`로 엔진 자동갱신).
- **Codex**: `/opt/homebrew/bin/npx -y @zed-industries/codex-acp` + env PATH(codex 바이너리 찾게). ChatGPT 구독(auth_mode=chatgpt), 과금 없음.
- **에이전트 고르기**: 에이전트 패널 **새 스레드 버튼 옆 ▾(드롭다운/메뉴)** → 에이전트 선택. 그냥 `+`만 누르면 마지막에 쓴 에이전트로 생성됨.
- 엔진·모델은 자동 최신. 어댑터·한글 Zed만 수동(위 1번).

## 4. 세션 사이드바

- 전 프로젝트 세션을 왼쪽에 표시(패치: `sidebar.rs`). **codnut_main 트리만** 노출(개인 레포 artemis·gisa 제외 — 범위 바꾸려면 sidebar.rs의 `"/codnut_main"` 필터 수정).
- 표시 시각은 **마지막 채팅 시각**(열어도 "1m" 안 됨 — 패치: `thread_metadata_store.rs`).
- 전체 세션이 안 보이면: 대부분 **archived** 상태. `db.sqlite`의 `sidebar_threads` 에서 `UPDATE ... SET archived=0` (Zed 종료 후, 백업 필수).

## 5. 문서 보기 (PDF·docx·hwp·pptx)

- 파일 열고 **`Cmd+Alt+V`** → `docview.py`가 **페이지를 이미지로** 변환 → `.view.md` 열림 → `Cmd+Shift+V`로 지면 그대로 보기.
- 마크다운은 그냥 `Cmd+Shift+V` (내장).
- 스캔 PDF 텍스트는 로컬 OCR(ocr.sh) 폴백.

## 6. 테마·아이콘
- 테마: macOS Classic Dark + 메인 배경만 애플 검정(`experimental.theme_overrides`).
- 파일 아이콘: Material Icon Theme (확장).
- 에이전트 아이콘: 이름으로 구분(패치 `agent_ui.rs`: claude→AiClaude, codex→AiOpenAi).
