# 아키텍처

## 전체 구성

```
 사용자
   │
   ▼
 한글 Zed.app  ──(ACP 프로토콜)──►  claude-agent-acp (패치됨)  ──►  Claude Code (구독)
   │                                     │
   │ UI: ko.json 반영된 한국어            │ settingSources: user·project·local
   │ 테마: 애플풍 검정 오버라이드          │  → CLI 와 동일 훅·CLAUDE.md·세션기록
   │                                     │
   └─ 프로젝트별 .zed/settings.json  →  전용 conda env 언어서버 자동 연결
```

## 구성 요소

| 요소 | 위치 | 역할 |
|---|---|---|
| 한국어 번역 | `i18n/ko.json` | 파일별 {영문:한글} 치환 맵. 빌드 시 소스에 반영 |
| Zed 설정 | `config/settings.json` | ACP 에이전트 서버 등록 + 애플 검정 테마 오버라이드 |
| 프로젝트 설정 템플릿 | `config/zed-project-settings-template.json` | 프로젝트별 Python env 고정 |
| 빌드 | `scripts/build.sh` | upstream Zed 받아 번역·설정 얹어 재컴파일 |

## 세션 통합 (ACP 패치)

Zed 는 ACP 어댑터의 기본 `listSessions`(acp-agent.ts) 경로를 쓴다. 이 경로에서
`~/.claude/projects` 전체를 노출하되, 자동화 세션(블로그 초안·논문 정제·Reflector·
Curator·`/usage` 등)은 패턴으로 숨긴다. 과거 세션은 Zed 의 Thread History → Import
Threads 로 불러와 이어간다.

## 번역 파이프라인

`zedl10n`(x6nux/zed-globalization)으로 소스 문자열을 추출하고, Claude 에이전트 여러
개가 청크를 나눠 병렬 번역한 뒤 병합해 `ko.json` 을 만든다. UI 문자열만 번역하고
테스트·로그·텔레메트리 문자열은 영문을 유지한다. 플레이스홀더는 위치까지 보존한다.

## 유지보수 흐름

1. Zed 새 버전 태그로 `ZED_VERSION` 변경
2. `scripts/extract.sh`(예정)로 신규/변경 문자열 추출
3. 변경분만 번역해 `ko.json` 보강
4. `scripts/build.sh` 재실행
