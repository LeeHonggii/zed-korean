# 사용법

한글 Zed + Claude Code(ACP)를 설치하고 쓰는 법.

## 1. 빌드 & 설치

> 요구: 전체 **Xcode.app**(Metal 컴파일러), **Rust**(rustup), **Python 3**.
> 처음엔 Xcode 라이선스 동의가 필요하다: `sudo xcodebuild -license accept`

```bash
git clone https://github.com/LeeHonggii/zed-korean.git
cd zed-korean
./scripts/build.sh          # upstream Zed 받아 번역·설정 얹어 빌드 (30~90분)
```
빌드가 끝나면 `~/Tools/zed-src/target/release/bundle/osx/` 에 앱이 생긴다. `/Applications` 로 옮긴 뒤 서명이 없으므로 한 번:
```bash
sudo xattr -rd com.apple.quarantine /Applications/<앱이름>.app
```

## 2. Claude Code 연결 (ACP)

`config/settings.json` 을 `~/.config/zed/settings.json` 에 반영한다. 핵심은 `agent_servers` 등록:

```jsonc
"agent_servers": {
  "Claude Code (전체세션)": {
    "type": "custom",
    "command": "node",
    "args": ["/Users/<나>/Tools/claude-agent-acp/dist/index.js"],
    "env": {
      "CLAUDE_ACP_ALL_SESSIONS": "1",   // 전 프로젝트 세션 노출
      "CLAUDE_ACP_HIDE_AUTOMATION": "1" // 자동화 세션 숨김
    }
  }
}
```
Claude Code CLI 가 구독으로 로그인돼 있으면 그대로 쓰인다(API 과금 없음).

## 3. 쓰는 법

### AI가 작업하는 걸 보기
1. **프로젝트 폴더를 개별로 연다** (루트 말고 `01_hrd-net` 같은 폴더). 그래야 그 프로젝트 Python env·CLAUDE.md 가 자동으로 붙는다.
2. 오른쪽 에이전트 패널에서 **새 스레드** → Claude 에게 지시 → 파일 읽기·수정·명령 실행을 실시간으로 본다.

### 이전 대화 이어가기
- 왼쪽 **스레드 목록**에서 클릭하면 오른쪽에 그 대화가 열린다.
- 전체 과거 세션은 왼쪽 아래 **시계(🕐)** → 목록에서 선택. (처음 한 번은 Thread History → **Import Threads** 로 불러온다.)
- 자동화 세션(블로그·논문·로그)은 숨겨져 실제 작업 세션만 보인다.

### 저장 규칙 (자동 적용)
Zed 에서 띄운 Claude 도 터미널 CLI 와 같은 규칙을 따른다:
- 새 문서·배포물 파일명 `YYMMDD_` 프리픽스
- 산출물 `output/`, 데이터 `data/`, 외부 문서 `documents/`
- 대화 기록은 `~/.claude/projects/<프로젝트>/*.jsonl` (CLI 와 동일 위치 → 터미널에서 `claude --resume` 로도 이어감)

### 프로젝트별 Python 환경
각 프로젝트 `.zed/settings.json` 에 전용 conda env 를 지정하면 언어서버가 자동으로 그 환경을 쓴다. 템플릿: `config/zed-project-settings-template.json`.
