## 3. 빌드·설치 (수정할 때마다)
```bash
cd ~/Tools/zed-src && export PATH="$HOME/.cargo/bin:$PATH"
cargo check --release -p <고친crate>      # 먼저 컴파일 확인(빠름)
./script/bundle-mac -l                     # 빌드. 끝 "dmg-license not found"는 무해
osascript -e 'quit app "Zed"'; sleep 2; pkill -x zed; sleep 1
BUILT=~/Tools/zed-src/target/aarch64-apple-darwin/release/dmg/Zed.app
rm -rf /Applications/Zed.app && cp -R "$BUILT" /Applications/Zed.app && xattr -cr /Applications/Zed.app
open /Applications/Zed.app
```
- ⚠ **`workspace`/`project`/`sidebar` 같은 핵심 크레이트를 고치면 최종 `zed` 바이너리 재링크로 30~90분** 걸림. 말단 크레이트는 빠름. → 여러 UI 변경은 모아서 한 번에 빌드.
- 설정·테마·아이콘·키맵·번역(ko.json replace 후 제외)은 재빌드 없이 즉시 반영.
- 빌드 요구: 전체 Xcode.app + Metal Toolchain(Xcode→Settings→Components), Rust(rustup), `cargo install cargo-about`. 모두 설치 완료.

## 4. gpui 패치 팁(실전)
- 이미지 렌더: `gpui::img(Arc<Path>)` + `.w(relative(zoom))`. 스크롤: `div().id().overflow_scroll().track_scroll(&ScrollHandle)`. 드래그팬: on_mouse_down/move/up + `scroll_handle.set_offset(start+delta)`.
- 스크롤 메서드는 `StatefulInteractiveElement`(+`.id()`), `background_spawn`은 `AppContext` trait, 둘 다 import 필요.
- 바이너리 못 여는 파일은 `Editor::for_broken_project_item`→`InvalidItemView`로 감(이걸 뷰어로 재활용). 텍스트(html)를 뷰어로 보내려면 `Buffer::try_open`에서 Internal 에러.
- 한글은 바이너리에서 `grep -a`로 확인(`strings`는 ASCII만). 주석은 컴파일시 제거되니 주석으로 패치확인 금지.

## 5. 문서뷰어 변환기(docview.py)
- pdf→pymupdf 페이지 PNG / office·hwp→soffice→pdf→PNG / html→playwright 전체스크린샷 / 스캔PDF→ocr.sh.
- 출력 `~/.cache/docview/<stem>_pages/*.png`. InvalidItemView가 이 PNG들을 렌더.
- harness-tools 파이썬(pymupdf·playwright 있음) 사용.
