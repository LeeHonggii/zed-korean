## 4. gpui 패치 팁(실전)
- 이미지 렌더: `gpui::img(Arc<Path>)` + `.w(relative(zoom))`. 스크롤: `div().id().overflow_scroll().track_scroll(&ScrollHandle)`. 드래그팬: on_mouse_down/move/up + `scroll_handle.set_offset(start+delta)`.
- 스크롤 메서드는 `StatefulInteractiveElement`(+`.id()`), `background_spawn`은 `AppContext` trait, 둘 다 import 필요.
- 바이너리 못 여는 파일은 `Editor::for_broken_project_item`→`InvalidItemView`로 감(이걸 뷰어로 재활용). 텍스트(html)를 뷰어로 보내려면 `Buffer::try_open`에서 Internal 에러.
- 한글은 바이너리에서 `grep -a`로 확인(`strings`는 ASCII만). 주석은 컴파일시 제거되니 주석으로 패치확인 금지.
- ⚠ **빌드가 도는 중에 소스를 고치면 그 빌드에 안 들어갈 수 있다**(10/27 실제로 접기 패치가 빠진 채 설치됨). 고칠 걸 다 고친 뒤 빌드하고, 설치 전에 패치 문구가 바이너리에 있는지 확인: `python3 -c "print(open('<app>/Contents/MacOS/zed','rb').read().count('고유문구'.encode()))"`.
- ⚠ **이 대화가 Zed 안에서 돌면 설치(=Zed 종료)가 대화를 끊는다.** 빌드는 Claude 백그라운드(run_in_background, 화면에 보임)로, 설치만 `nohup … reinstall.sh & disown` 으로 떼어 실행. `KEEP_ARCHIVED=1` 권장(보관 스레드 안 되살림).
- 재설치마다 앱 서명이 바뀌어 **화면 녹화 권한이 풀린다**(스크린샷 못 찍음) — 시스템 설정에서 Zed 껐다 켜기. 서명 고정은 미해결.
- 인터넷 끊기면 `bundle-mac` 이 git 바이너리 다운로드 단계에서 실패 → 새 앱이 안 만들어짐. 설치 전 바이너리 확인 필수.

## 8. 캔버스 그림판 → pptx (10/27)
- **목적**: Zed 안에서 채팅하면서 박스를 그려 발표자료를 만든다. 파일은 옵시디언과 같은 JSON Canvas(`.canvas`) — 옵시디언에서 그린 것도 열리고, 모르는 필드·edge·link 노드는 그대로 보존.
- **조작**: 「＋ 슬라이드」=16:9 틀(1600×900, 마지막 슬라이드 아래). 틀 안 빈 곳 드래그=새 박스(10단위 스냅). 박스 끌기=이동, 선택 박스 오른쪽아래 손잡이=크기. 슬라이드는 위 제목 띠를 끌면 안의 박스까지 같이 이동. 스크롤=이동, 핀치·⌘스크롤=확대, Alt/가운데 버튼 드래그=이동. Delete/Backspace=선택 삭제, Esc=선택 해제. 색 견본=선택 박스/슬라이드 색. 아래 입력칸=선택한 박스 글/슬라이드 제목(입력 즉시 저장).

### 10-2. 타이틀바 가운데: Claude → GPT → Jev 남은 양
